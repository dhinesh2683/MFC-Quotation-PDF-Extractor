# MFC Quotation PDF Extractor

A Python-based Streamlit application that extracts quotation details from PDF files and exports the data to Excel and MySQL.

## Features
- Upload multiple PDF files.
- Automatically extract quotation details.
- Support multiple quotation formats.
- Remove duplicate PDF files.
- Export extracted data to Excel.
- Store extracted data in MySQL.
- Validate extracted information.

## Technologies Used
- Python
- Streamlit
- Pandas
- PDFPlumber
- OpenPyXL
- MySQL

```

Run the application:

```bash
streamlit run app.py
```
